# Trabajo académico: árboles B en Java

Ejercicio de estructuras de datos con implementaciones de árboles B y nodos genéricos.

## Capacidades técnicas

Uso de clases, genéricos y estructuras de datos en Java.

## Contenido

- [BNodeGeneric.java](BNodeGeneric.java): nodo genérico.
- [BTree.java](BTree.java): implementación de árbol B.
- [BTreeGeneric.java](BTreeGeneric.java): variante genérica.

## Uso

Con un JDK instalado, compilar desde la raíz:

```bash
javac BNodeGeneric.java BTree.java BTreeGeneric.java
```

Para ejecutar una demostración, utilizar la clase que contenga el método `main` o incorporar un programa de prueba. No se publica un comando de ejecución sin confirmar el punto de entrada.
